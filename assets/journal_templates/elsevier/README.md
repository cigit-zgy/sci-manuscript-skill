# Elsevier template resource

- Template name: `elsarticle`
- Template type: official Elsevier journal article class
- Publisher source: https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions
- Class source: https://assets.ctfassets.net/o78em1y1w4i4/UtkmcwzDXZeIUVlmhPGFm/4923f3c3bcc768b6fc4fa4f26cf39d72/elsarticle.cls
- Package source: https://assets.ctfassets.net/o78em1y1w4i4/4MpsJHO0MOJ2xZuwGTAbOZ/7bc64af36477c5d6cfce335a1f872363/elsarticle.zip
- Download date: 2026-08-20
- Version: bundled class 3.3 (2020-11-20); template package 3.4 (2024-04-04)
- License: LaTeX Project Public License 1.2 or later for the class; the package README declares LPPL 1.3 or later.

`elsarticle.cls` and `elsarticle-num.bst` are unmodified files from Elsevier's
official assets. `template.tex` is the official numbered-reference example,
renamed from `elsarticle-template-num.tex` for a stable resource name.

Check the target journal's current Guide for Authors before submission.
