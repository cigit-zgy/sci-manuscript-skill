# KXTB-CAS fonts

This directory belongs only to the KXTB-CAS publisher resource. Runtime staging copies legally installed Times New Roman and SimSun files here in the isolated build source. Font binaries are not redistributed with the package.

Required filenames: `TimesNewRoman-Regular.ttf`, `TimesNewRoman-Bold.ttf`, `TimesNewRoman-Italic.ttf`, `TimesNewRoman-BoldItalic.ttf`, `SimSun.ttf`, and `SimSun-Bold.ttf`. Missing exact fonts are a build error; no substitute family is selected.
