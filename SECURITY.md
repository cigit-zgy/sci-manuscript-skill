# Security Policy

## Supported versions

Security fixes are prepared for the latest published release. Older releases
may require an upgrade before a fix can be applied.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue containing credentials, private manuscript content, unpublished
review material, local paths, or exploit details.

Include the affected version, operating system, reproduction steps, impact, and
the smallest safe example. The maintainers will acknowledge the report, assess
scope, and coordinate remediation before public disclosure.
